ตัวอย่างระบบ LINE LIFF — ส่งตรวจสิ่งแวดล้อม

งานจุลชีววิทยา โรงพยาบาลธรรมศาสตร์เฉลิมพระเกียรติ · ISO 15189

หน้าจอในกรอบคือแอปจริงที่รันอยู่ กดใช้งานได้เลย

1 · ฝั่งผู้ส่งตรวจ (ในแอป LINE — Mobile First)

ตัวตนมาจาก liff.getProfile() ไม่ต้องตั้งรหัสผ่านซ้ำ · ตอนนี้แสดงเป็น โหมดพัฒนา เพราะยังไม่ได้ใส่ LIFF ID

1 จองคิว

ปฏิทินเปิดเฉพาะ จันทร์–พุธ · ตัวเลขใต้วันที่คือจำนวนตัวอย่างที่มีคนจองแล้ว · แตะวันแล้วฟอร์มจะเลื่อนขึ้นมาพร้อมเติมชื่อจาก LINE ให้

2 แบบฟอร์มส่งตรวจ

ป้ายกำกับเปลี่ยนตามบริการ (WTS = สถานที่/หน่วยงาน, FOD = รายการอาหาร, STR = หมายเลขถุงเลือด) · ไม่มีช่องกรอกผลตรวจ โดยตั้งใจ

3–4 รอผล / ดูผล

เห็นเฉพาะใบที่ส่งด้วยบัญชี LINE ตัวเอง · ใบที่ออกผลแล้วแตะเพื่อเปิดใบรายงานฉบับเต็ม

2 · การ์ดแจ้งเตือนเข้ากลุ่ม LINE ห้องแล็บ

วาดจาก JSON ของจริงที่ liff-flex.js สร้างขึ้น (หน้าตาในแอป LINE จะใกล้เคียงนี้)

3 · ฝั่งนักเทคนิคการแพทย์ (คอมพิวเตอร์ จอกว้าง)

หน้านี้บังคับล็อกอินก่อน — กดปุ่มด้านล่างเพื่อเข้าสู่ระบบด้วยบัญชีเจ้าหน้าที่ของท่าน แล้วหน้าตารางจะแสดงในกรอบ

เปิดเต็มจอ

ซ้าย = คิวใบที่รอลงผล (ใบที่มาจาก LINE มีป้ายกำกับ) · ขวา = ตารางคีย์ผล คอลัมน์เปลี่ยนตามบริการ · Enter/↓ ลงแถวถัดไปโดยไม่ต้องจับเมาส์

หน้านี้เป็นหน้าตัวอย่างสำหรับดูภาพรวม ไม่ได้เป็นส่วนหนึ่งของระบบที่ผู้ใช้เข้าถึง
