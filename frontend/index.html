ติดตามสถานะการตรวจวิเคราะห์ และดาวน์โหลดรายงานผลที่ได้รับอนุมัติ (ISO 15189)

เลขที่ส่งตรวจ บริการ หน่วยงานส่งตรวจ วันที่ส่งตรวจ จำนวนตัวอย่าง สถานะ ผู้ตรวจ / ผู้อนุมัติ (ทน.) การจัดการ
กำลังโหลดข้อมูลจริงจากฐานข้อมูล Supabase...

📖 คู่มือการใช้งานระบบรายงานผลตรวจสิ่งแวดล้อม

ขั้นตอนการส่งตรวจ (สำหรับหน่วยงานผู้ส่งตรวจ):

  1. เลือกบริการที่ต้องการส่งตรวจ (เช่น Air Sampling, Water, Food) แล้วกดปุ่มสีทอง "ส่งตรวจ"
  2. กรอกข้อมูลหน่วยงาน, วันที่ส่งตรวจ และระบุจำนวนจุดเก็บตัวอย่าง
  3. เลือกหอผู้ป่วย (Ward) และระบุตำแหน่งที่เก็บตัวอย่างให้ชัดเจน
  4. กดบันทึกข้อมูล ระบบจะออกรหัสใบส่งตรวจ (เช่น SUB-AIR-YYMM-XXX)

ขั้นตอนการตรวจและออกรายงาน (สำหรับเจ้าหน้าที่ห้องแล็บ):

  1. เมื่อรับสิ่งส่งตรวจ ให้เปลี่ยนสถานะเป็น "รับตัวอย่างแล้ว (Received)"
  2. เมื่อเริ่มบ่มเพาะเชื้อ ให้เปลี่ยนเป็น "กำลังตรวจวิเคราะห์ (In Progress)"
  3. บันทึกผลการนับโคโลนี (Bacteria CFU / Fungus CFU)
  4. นักเทคนิคการแพทย์เลือกชื่อผู้รายงานผล และหัวหน้าห้องแล็บตรวจสอบอนุมัติผล (ระบบบังคับต้องเป็นคนละท่านตาม ISO 15189)
  5. ระบบจะสร้างรายงาน PDF พร้อม SHA-256 Hash เพื่อความถูกต้อง
